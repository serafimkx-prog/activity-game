# Activity — Полная техническая спецификация (Full Tech Spec)

Данный документ описывает внутреннее устройство, алгоритмы и архитектурные решения проекта **Activity**.

## 1. Технологический стек
*   **Frontend:** HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript (ES6+).
*   **Audio:** Web Audio API (программная генерация звуков без внешних файлов).
*   **Graphics:** Canvas API (для режима рисования).
*   **Data:** JSON (словари и метаданные).

## 2. Архитектура данных
### Глобальное состояние (`state`)
```javascript
{
  teams: [
    {
      name: String,
      position: Number (0-41),
      color: String (Hex),
      players: String[],
      explainerIdx: Number // Индекс игрока, чей сейчас черёд объяснять
    }
  ],
  teamIndex: 0, // Индекс активной команды
  cellMode: { key, icon, name, css, hint }, // Текущий режим клетки
  config: { 
    turnTime: 60, 
    openRoundEnabled: true 
  },
  pools: { DRAW, EXPLAIN, ACT }, // Тасованные массивы слов
  indices: { DRAW, EXPLAIN, ACT }, // Текущие указатели в пулах
  gameInProgress: Boolean // Флаг для кнопки "Продолжить"
}
```

## 3. Игровые системы и алгоритмы

### 3.1. Генерация игрового поля
Поле состоит из **41 клетки** (0-40) + финиш (41).
Распределение режимов фиксировано:
*   **14 клетки** — Объяснение (E)
*   **14 клетки** — Пантомима (A)
*   **13 клеток** — Рисование (D)
Алгоритм: Массив из 41 элемента перемешивается методом Тасования Фишера-Йетса при старте игры.

### 3.2. Визуализация поля (Snake Path)
Поле рендерится в сетке **7x6**.
*   **Четные ряды (0, 2, 4):** Слева направо.
*   **Нечетные ряды (1, 3, 5):** Справа налево.
Это создает "змейку", где выход одной строки соединяется с началом следующей через специальные визуальные разделители (`board-sep`).

### 3.3. Аудио-движок (Web Audio API)
Звуки генерируются через `OscillatorNode`.
*   **Типы волн:** `sine` (мягкие), `square` (резкие/бип), `sawtooth` (агрессивные/таймер), `triangle` (глухие).
*   **Метод:** `exponentialRampToValueAtTime` используется для плавного затухания (эффект колокольчика или щелчка).
*   **События:** Тиканье (urgent/normal), успех, провал, выбор карты, навигация, столкновение, открытый раунд.

### 3.4. Режим Рисования (Canvas)
*   **Разрешение:** Фиксированное 520x280 (масштабируется CSS под экран).
*   **Инструменты:** Выбор из 5 цветов, 3 размера кисти (2px, 4px, 8px).
*   **События:** Поддержка `mousedown/mousemove` и `touchstart/touchmove` для мобильных устройств.

## 4. Игровая логика и Правила

### 4.1. Ротация объясняющих
Внутри команды игроки меняются каждый ход по кругу: `explainerIdx = (explainerIdx + 1) % team.players.length`. Это гарантирует, что один и тот же человек не будет объяснять два раза подряд.

### 4.2. Алгоритм Столкновения (Collision)
Если команда $A$ после успешного хода перемещается на клетку $N$, где уже стоит команда $B$:
1.  Команда $B$ перемещается на $N-1$ (минимум в 0).
2.  Если на $N-1$ тоже кто-то стоял, цепная реакция **не** происходит (сдвигается только первая найденная команда).

### 4.3. Открытый Раунд (Красная карточка)
Вероятность появления: **10%**.
*   **Угадывают все:** Кто первый нажал кнопку своей команды в интерфейсе, тот получает очки.
*   **Система очков:**
    *   Угадавшая команда получает столько очков, **сколько указано на карточке** (3, 4 или 5 в зависимости от выбранной сложности).
    *   Если угадала команда-исполнитель: получает обычные очки карточки.
    *   Если угадала команда-соперник: соперник получает очки карточки, исполнитель получает **+2 очка утешения**.
*   **Столкновение:** Правило "Столкновения" действует как обычно — фишка соперника отступает на 1 клетку назад.

## 5. Работа со словарями
Загрузка через `dictionaries.json` позволяет:
1.  Отображать метаданные (иконка, подзаголовок, количество слов).
2.  Поддерживать "заблокированные" (locked) словари для будущего расширения.
3.  Использовать разные файлы (например, `words_geo.json`).

## 6. Жизненный цикл экрана (State Machine)
`showScreen(id)` выполняет:
1.  Остановку всех `setInterval`.
2.  Скрытие всех слоев `.screen`.
3.  Отображение целевого слоя.
4.  Скролл в начало страницы (удобно для мобильных).
