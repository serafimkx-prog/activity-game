# 🎭 Activity — Веб-версия настольной игры

Полноценная браузерная реализация популярной настольной игры Activity. Весь драйв, эмоции и правила оригинальной игры в удобном цифровом формате.

---

## 🚀 Особенности
- **Чистый стек:** Без React/Vue, только Vanilla JS — работает быстро даже на старых устройствах.
- **Программный звук:** Уникальные звуковые эффекты, генерируемые на лету через Web Audio API.
- **Интерактивный холст:** Встроенный графический редактор для режима "Рисование".
- **Умное поле:** Автоматическая генерация карты и логика "столкновения" команд.
- **Гибкий состав:** От 2 до 6 команд с поддержкой неограниченного списка игроков внутри каждой.

---

## 🛠 Как запустить

Игра требует локального сервера для загрузки словарей (Fetch API).

1. Перейдите в папку проекта:
   ```bash
   cd activity-game
   ```
2. Запустите сервер (любым способом):
   - **Python:** `python3 -m http.server 8080`
   - **Node.js (http-server):** `npx http-server`
   - **VS Code:** Плагин "Live Server".

3. Откройте в браузере: `http://localhost:8080`

## 📝 Правила и Механики

### Цель игры
Первым довести фишку своей команды до **41-й клетки (Финиш)**.

### Режимы объяснения
Тип задания определяется цветом клетки, на которой стоит ваша фишка:
1.  🗣️ **Объяснение (Explain):** Только слова. Нельзя называть однокоренные, использовать переводы или произносить само слово.
2.  🙌 **Пантомима (Act):** Только жесты и мимика. Полная тишина.
3.  🎨 **Рисование (Draw):** Нельзя говорить, использовать буквы или цифры в рисунке.

### Сложность и Очки
При каждом ходе игрок выбирает одну из трех сложностей:
- **3 очка (Легкая):** Обиходные слова.
- **4 очка (Средняя):** Более сложные понятия.
- **5 очков (Сложная):** Абстрактные термины или фразы.

### Особые события
- **Столкновение:** Если ваша фишка встает на клетку, где уже находится соперник, вы "выбиваете" его — команда соперника отступает на **1 клетку назад**.
- **Открытый раунд (Красная карточка):** Выпадает случайно (10%). В этом раунде слово угадывают **все команды**. Угадавшая команда получит столько очков, сколько указано на карточке (3/4/5). Если угадает соперник, исполнитель получит +2 очка утешения.

## ⚙️ Настройка своего словаря

Вы можете добавить свои слова, отредактировав файл `words.json`.

**Структура файла:**
```json
{
  "DRAW": {
    "3": ["Кот", "Дом"],
    "4": ["Гравитация", "Уют"],
    "5": ["Сингулярность", "Метафора"]
  },
  "EXPLAIN": { ... },
  "ACT": { ... }
}
```
После внесения изменений просто обновите страницу в браузере.

## 📂 Структура проекта
- `index.html` — Разметка всех экранов (Setup, Board, Explaining, Results).
- `script.js` — Ядро игры: аудио-движок, canvas, стейт-менеджмент.
- `style.css` — Адаптивный дизайн (Mobile First).
- `dictionaries.json` — Список доступных словарей и их метаданные.
- `words.json` — Основная база слов.
- `GAME_SPEC.md` — Глубокое описание технических алгоритмов (для разработчиков).

---

## 👨‍💻 Для разработчиков
Проект спроектирован как SPA (Single Page Application). Состояние игры хранится в объекте `state`. Все переходы между экранами управляются функцией `showScreen()`, которая также отвечает за сброс таймеров и очистку контекста.
